# 布丁的注音小教室 🍮

面向零基础学习者的响应式台湾国语注音学习网站，使用 React、TypeScript、Vite 和 Tailwind CSS。无需登录、数据库、环境变量、API 密钥或付费服务。教学内容为台湾国语注音，不与台湾台语混用。

## 运行与验证

需要 Node.js 22.12+（当前验证版本 24.19.0）及 npm。

```sh
npm ci
npm run dev
npm run build   # TypeScript 检查 + 生产构建至 dist/
npm test        # 课程、进度、练习、奖励和解锁回归测试
npm run preview # 预览 dist/，默认端口 4173
```

本地开发或预览应访问终端地址下的 `/pudding-bopomofo/`。云平台需要支持相应端口转发才能提供浏览器预览。生产环境只需托管 `dist/`。

## 完整课程旅程

课程配置在 `src/curriculum.ts`。共 15 节可实际学习和练习的课程，按完成顺序逐课解锁，无每日上限：

| 阶段 | 课程 |
| --- | --- |
| 基础注音（11 课，37 个符号） | ㄅㄆㄇㄈ → ㄉㄊㄋㄌ → ㄍㄎㄏ → ㄐㄑㄒ → ㄓㄔㄕㄖ → ㄗㄘㄙ → ㄧㄨㄩ → ㄚㄛㄜㄝ → ㄞㄟㄠㄡ → ㄢㄣㄤㄥ → ㄦ |
| 声调学习 | 四声、轻声及标记位置，包含三声变调的入门提示 |
| 注音拼读 | 两拼、含介音的拼读，以及 xu 中 ü 省点等拼写提示 |
| 生活词语 | 花、猫、水、茶的读音和词义 |
| 简单句子阅读 | 四个生活短句，练习注音、句意、动作及标点 |

首页直接展示进度与全部 11 节基础课；四个进阶阶段放在「拼读学习」入口。课程切换、记录及练习沿用原解锁规则。完成上一课立即解锁下一课，完成提示后可直接继续。旧已完成课程始终可复习。基础 11 课全部完成后显示简短完成标记；每个进阶阶段仍是一节完整入门课。

基础课包含符号、适用的汉语拼音对照、发音方法、口型和例字的完整注音。声母和韵符采用不同提示，说明 i/u/ü 的音节拼写、ㄜ/ㄝ 区分、zh/ch/sh/r/z/c/s 后拼音 i 的特殊读法。这里用文字讲解发音，没有录音或语音评分。课程完成标记代表用户完成学习，不代表通过发音测评。

## 简洁学习界面

顶部仅保留「学习课程、注音练习、拼读学习、学习记录」四个入口，手机端也直接显示四项导航。移除大型 Hero、欢迎宣传语、插画和动画地图。课程页只保留课程切换、学习内容、例字、拼音和上下步操作。游戏状态继续保留，但不展示糖果和庆祝装饰。

## 互动练习

每课题库至少 14 题（基础课为 15–28 题），每组随机抽取 12 题并随机排列选项，优先选取上一组未出现的题目。基础课覆盖符号辨认、拼音对应、例字注音与口型知识；后续阶段使用专门配置的声调、拼读、词义和阅读理解题，不将韵母或句子套用为声母。

综合练习仅从当前解锁课程均衡抽取，最多 24 题，不出现重复题目。综合抽样的每课题量可能不足完整一组，所以不发放分课首次练习或满分奖励；旧已领取的奖励不会扣回。完成后保存总体及分课抽样成绩，但标记为不具备课程奖励资格，刷新后不会误补发糖果。

可筛选注音识别、拼音对应、文字发音辨认和注音拼读题型。错题复习读取尚未答对的已保存错题，正确回答后标记为已改正，保留原错答记录。题组结束显示正确率、错题和解释，支持回到对应课程复习与重新练习。新增基础符号课通过模型自动生成题目；声调、拼读、词语与阅读课配置明确的专属题库。

## 进度与学习记录

- `pudding-learning-v1`：沿用原课程进度键及前两课 ID `bpmf` / `dtnl`，不重置旧记录。
- `pudding-practice-v1`：分课练习次数、最近成绩与时间；新增可选 `rewardEligible` 区分综合抽样，兼容旧记录。
- `pudding-practice-scope`：最近选择的练习课程。
- `pudding-mistakes-v1`：逐题保存错误答案、错误次数和改正状态，未完成题组的错题也会保存。
- `pudding-answer-stats-v1`：累计已完成题组的答题数与正确数，不重复计算综合练习的分课记录。旧数据以各课最近成绩为统计起点，不虚构旧版没有保存的历史错题。
- `pudding-game-v1`：唯一领奖标记及复习状态。每课首次学习 +10、首次完成分课练习 +5、首次满分额外 +3，重复学习或刷题不会重复领奖。已有记录按可确认情况一次性补奖。

完成学习解锁下一关，复习单独标记，不会代替学习。刷新回到首页，进度、糖果、已完成练习成绩和毕业成就保留；未完成的题组重新开始。数据仅属于当前浏览器来源，不跨设备同步，清除浏览器数据会清除记录。本地记录不会自动转移到 Pages。存储受限时仍能学习，并提示哪些状态无法保存。

奶油绿与米白色界面，无装饰动画。原布丁图标文件保持不变；图标生成所需绘制代码独立保存在 scripts/，不再加载进学习界面。原奖励状态和接口仍保存在 `src/game.ts`，不重置已获奖励。

## GitHub Pages 部署与合并

Settings → Pages → Source 选择 **GitHub Actions**。合并到 `main` 后，现有工作流自动执行锁定依赖安装、TypeScript 检查、构建与测试，再部署 `dist/`。也可在 Actions → Deploy to GitHub Pages 选择 main 手动运行。

网站：https://buding135790.github.io/pudding-bopomofo/

Vite `base` 为 `/pudding-bopomofo/`，图标引用使用 `%BASE_URL%`。以 React 状态切换页面，无路径路由，不需要 404 回退。

当前 UI 简化分支 `feat/quiet-study-ui`，请创建目标为 main 的 PR，审核合并后等待部署完成。
